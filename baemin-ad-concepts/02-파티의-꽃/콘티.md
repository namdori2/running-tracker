# 아이디어 2 — 파티의 꽃

- **배경**: 파티룸 (조명, 풍선, 빈 테이블)
- **길이**: 30초
- **등장인물**: 몇 년 만에 모인 친구들 4~5명, "민이" (끝까지 등장 X → 정체는 배민)
- **톤**: 반가움 → 기대감·긴장감(코믹) → 터지는 환호
- **핵심 반전**: 모두가 기다린 친구 "민이" = 배민 배달

## 연출 포인트
- 1컷의 **빈 테이블**과 12컷의 **꽉 찬 테이블**을 같은 구도로 찍어 대비.
- 4~6컷 대사는 "민이"가 진짜 인싸 친구처럼 들리게 — 시청자도 사람이라 믿도록.
- 8컷은 과장된 서스펜스(호러/스릴러 패러디)로 웃음 유발.
